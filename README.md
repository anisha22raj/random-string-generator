# 🌻 Random String Generator

A modern and responsive Random String Generator built with **React** and **Vite**. This application allows users to generate secure and customizable random strings using React Hooks.

## ✨ Features

- 🎲 Generate random strings instantly
- 📏 Adjustable string length
- 🔠 Include Uppercase Letters
- 🔡 Include Lowercase Letters
- 🔢 Include Numbers
- 🔣 Include Special Characters
- 📋 Copy generated string with one click
- ⚡ Built using React Hooks
- 📱 Fully Responsive Design
- 🎨 Fun Yellow UI Theme

---

## 🛠️ Technologies Used

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3

---

## ⚛️ React Hooks Used

- **useState** – Manage application state
- **useEffect** – Generate an initial random string
- **useCallback** – Optimize the string generation function

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/anisha22raj/random-string-generator.git
```

Navigate to the project folder:

```bash
cd random-string-generator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```

---

## 🚀 Deploy

```bash
npm run deploy
```
